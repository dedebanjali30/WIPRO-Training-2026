# Wipro Capstone Assignment 1 - Project Report

## Title
Automate a Web Application Using Selenium WebDriver with Python

## Objective
To automate an e-commerce customer purchase workflow using Python and Selenium WebDriver.

## Application Under Test
Automation Exercise.

## Tools
- Python
- Selenium WebDriver
- Google Chrome
- JSON
- HTML

## Test Scenario
1. Launch browser.
2. Open application.
3. Login with valid credentials.
4. Verify login.
5. Navigate to Products.
6. Search for Blue Top.
7. Open product details.
8. Set quantity to 3.
9. Add product to cart.
10. Open shopping cart.
11. Verify product and quantity.
12. Capture screenshots.
13. Generate execution report.

## Framework
Page Object Model is used with LoginPage, ProductsPage, ProductPage and CartPage classes.

## Expected Result
The product should be successfully searched, added to the cart and displayed with the requested quantity.

## Conclusion
The project demonstrates web application automation using Python and Selenium WebDriver, including locators, waits, assertions, screenshots, JSON test data and execution reporting.
