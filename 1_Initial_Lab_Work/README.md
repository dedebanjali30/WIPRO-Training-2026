# Wipro Initial Lab Work

This folder contains the initial lab exercises completed as part of the Wipro Training 2026 program.

## Modules Covered

| Module | Topic | Description |
|---|---|---|
| 1 | Automation with Selenium | Web automation using Python and Selenium WebDriver |
| 2 | Unit Test Frameworks | Python unittest, pytest, fixtures, parameterization and reporting |
| 3 | Python BDD & RESTful API | BDD testing with Behave and REST API automation |
| 4 | Robot Framework | Test automation using Robot Framework and API validation |

## Contents

Each module contains relevant source code, test data, screenshots and supporting files.

### Module 1 – Automation with Selenium
Covers Selenium WebDriver based browser automation using Python.

### Module 2 – Unit Test Frameworks
Covers unittest, pytest, fixtures, parameterization, Page Object Model and HTML reporting.

### Module 3 – Python BDD & RESTful API
Covers Behavior Driven Development using Behave and REST API automation.

### Module 4 – Robot Framework
Covers Robot Framework fundamentals, reusable keywords, data-driven testing, tags, Python integration and API testing.

## Technologies Used

- Python
- Selenium WebDriver
- pytest
- unittest
- Behave
- REST APIs
- Robot Framework
