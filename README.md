# WIPRO Training 2026

This repository contains the work completed as part of the Wipro Training 2026 program.

## Repository Contents

| Folder | Description |
|---|---|
| `1_Initial_Lab_Work` | Module-wise initial lab exercises, automation codes, test data, screenshots and reports |
| `2_Capstone_Project` | Wipro Capstone Assignment – Python Selenium |
| `3_Certificates` | Certificates obtained during the training program |

## 1. Initial Lab Work

The Initial Lab Work consists of four modules:

1. **Automation With Selenium**
   - Selenium WebDriver with Python
   - Web element interaction
   - Locators
   - Page Object Model
   - Data-driven automation

2. **Unit Test Frameworks**
   - Python `unittest`
   - `pytest`
   - Fixtures
   - Parameterization
   - Assertions
   - Page Object Model
   - HTML reporting

3. **Python BDD & RESTful API**
   - Behavior Driven Development
   - Behave
   - Gherkin
   - REST API automation
   - GET and POST requests
   - API response validation
   - Data-driven API testing

4. **Robot Framework**
   - Robot Framework fundamentals
   - Test cases and keywords
   - Data-driven testing
   - Tags
   - Python custom keywords
   - API testing and assertions

## 2. Capstone Project
